### 要点说明

#### 什么时候分配 ID？

```
新建 Pipe 时（CreateFacility）：
  data.id = Guid.NewGuid().ToString()
  → 实例化 GameObject
  → identity.AssignId(data.id)    // 设置组件 ID

从 JSON 加载时（Start）：
  data.id = progress.json 中已保存的 id
  → 实例化 GameObject
  → identity.AssignId(data.id)    // 用原有 ID，不重新分配
```

**关键规则：ID 一生不变。** 新建时生成，存进 JSON，以后每次加载都用同一个。

#### AssignId 为什么是方法不是直接 set？

```csharp
// 封装成方法而不是直接 set Id，可以加保护逻辑
public void AssignId(string newId)
{
    if (!string.IsNullOrEmpty(id))
    {
        Debug.LogWarning($"FacilityIdentity 已有 ID: {id}，跳过重新分配");
        return;
    }
    Id = newId;
}
```

这样防止不小心覆盖已有 ID。

#### 2. DeleteFacility 完整逻辑

```csharp
public bool DeleteFacility(string id)
{
    FacilityData data = progressData.facilities.Find(f => f.id == id);
    if (data == null || data.isDeleted) return false;

    data.isDeleted = true;
    isDirty = true;
    TryAutoSave();                     // ← 启动防抖保存
    OnFacilityDeleted?.Invoke(id);     // ← 广播事件
    return true;
}
```

#### 3. RestoreFacility 完整逻辑

```csharp
public bool RestoreFacility(string id)
{
    FacilityData data = progressData.facilities.Find(f => f.id == id);
    if (data == null || !data.isDeleted) return false;

    data.isDeleted = false;
    isDirty = true;
    TryAutoSave();
    OnFacilityRestored?.Invoke(id);
    return true;
}
```

#### 4. Start() 加载时跳过已删除设施

#### 6. 获取最近删除的设施（R 键恢复用）

```csharp
public string GetRecentDeletedFacilityId()
{
    // 从 facilities 中找 isDeleted == true 且 addedTime 最新的
    FacilityData recent = null;
    foreach (var f in progressData.facilities)
    {
        if (!f.isDeleted) continue;
        if (recent == null || string.Compare(f.addedTime, recent.addedTime) > 0)
            recent = f;
    }
    return recent?.id;
}
```
